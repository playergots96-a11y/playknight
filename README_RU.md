# AutoStock Editor v2 — генератор проекта DaVinci Resolve

Приложение берёт озвучку (аудио и/или текст сценария), подбирает стоковые видео под контекст каждых 4 секунд и собирает готовый таймлайн `.fcpxml` для DaVinci Resolve.

## Установка

1. Установите Python 3.10+ и FFmpeg (нужен для Whisper):
   - Windows: `winget install ffmpeg`
   - macOS: `brew install ffmpeg`
   - Linux: `sudo apt install ffmpeg`
2. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```
   python main.py
   ```

## Использование

1. Вставьте API-ключи (для каждого сервиса можно указать основной и резервный):
   - **Pexels** (pexels.com/api) — обязателен, хотя бы один.
   - **OpenRouter** (openrouter.ai) — желателен: с ним ключевые слова подбирает LLM. Без него работает локальный упрощённый подбор.
   - Ключи автоматически сохраняются в `config.json` рядом с `main.py` (в открытом виде — не передавайте этот файл никому) и подставляются при следующем запуске.
2. Выберите **аудио (.mp3/.wav) ИЛИ сценарий (.txt)** — достаточно одного, но вместе точнее. Без аудио длительность оценивается по скорости чтения (~2.5 слова/сек), и таймлайн собирается без аудиодорожки.
3. Выберите папку вывода и нажмите **Generate DaVinci Project**.
4. Результат в папке вывода:
   - `имя_davinci.fcpxml` — таймлайн
   - `stock_media/` — скачанные стоки

## Импорт в DaVinci Resolve

**File → Import Timeline → Import AAF, EDL, XML, DRT, OTIO...** → выберите `.fcpxml`.
НЕ используйте «Import Project» — оно принимает только `.drp`.

## Запуск как отдельное приложение (без консоли)

**Вариант 1 — мгновенный (рекомендую):** положите `AutoStock Editor.vbs` рядом с `main.py` и запускайте двойным кликом — окно консоли не появится. Чтобы был красивый ярлык с иконкой: правый клик по .vbs → «Создать ярлык» → в свойствах ярлыка «Сменить значок» → выберите `icon.ico` → ярлык на рабочий стол или в панель задач.

**Вариант 2 — настоящий .exe:** запустите `build_exe.bat` (двойным кликом). Через несколько минут в `dist\AutoStock Editor\` появится `AutoStock Editor.exe` с иконкой — самостоятельное приложение, Python для запуска не нужен. Папка получится большой (~2 ГБ из-за Whisper/PyTorch) — это нормально. FFmpeg всё равно должен быть установлен в системе.

## Кнопка Cancel

Во время генерации кнопка Cancel (розовая) останавливает процесс: текущая операция аккуратно завершается, недокачанный файл удаляется, а всё уже скачанное остаётся в библиотеке и будет переиспользовано в следующий раз. Транскрипцию Whisper прервать на середине нельзя — отмена сработает сразу после неё.

## Видео и фото (примерно 70/30)

Теперь LLM для каждой сцены решает не только запрос, но и тип медиа: динамичные сюжеты — видео, а сложные/абстрактные/статичные идеи (карты, документы, портреты, схемы) — фото 16:9. Целевая пропорция ~70% видео / 30% фото, с жёстким потолком 40% фото. Фото-сцена при отсутствии подходящего фото возьмёт видео, и наоборот — пустых сцен не бывает.

## Локальная библиотека стоков

Скачанные стоки больше не пропадают: они складываются в **библиотеку** — папку `stock_library` рядом с `main.py` (путь можно поменять кнопкой «📦 Stock library»). Внутри — папки по ключевым словам:

```
stock_library/
├── forest/
│   ├── pexels_1234567.mp4
│   └── my_own_clip.mp4      ← можно докидывать свои файлы!
├── night_city/
└── ocean/
```

Как это работает:
- Перед скачиванием приложение ищет подходящую папку по словам запроса: запрос «snowy pine forest» найдёт папку `forest` (учитывается и множественное число: `forests` тоже сматчится).
- Видео берутся раньше фото; в одном ролике один и тот же файл не повторяется, пока в папке есть другие.
- Если в библиотеке ничего нет — сток скачивается с Pexels **и сохраняется в библиотеку**, так что она наполняется сама.
- Можно вообще без ключа Pexels: если библиотека уже наполнена, приложение соберёт ролик только из неё.
- Кладите в папки свои клипы (16:9!) — они будут в приоритете.

Быстро создать папки под ключевые слова:
```
python create_library_folders.py --starter        # готовый набор популярных тем
python create_library_folders.py forest, city, космос
```

Переключатель **«Copy used stocks into the project folder»**: если включён — использованные файлы дополнительно копируются в `stock_media/` внутри папки проекта (проект автономный, но тратится место). Если выключен (по умолчанию) — таймлайн ссылается на файлы прямо в библиотеке, и тогда библиотеку нельзя перемещать, пока проекты в работе.

## Как подбираются стоки

- Каждая сцена на таймлайне — ровно **4 секунды** (последняя короче; совсем крошечный хвост приклеивается к предыдущей).
- Все стоки строго **16:9 landscape**, минимум 720p; приоритет: разрешение ближе к 1080p, затем мягкое предпочтение ~60 fps (не обязательное).
- Ключевые слова — **широкие популярные** визуальные образы по контексту (речь про «диаметр леса» → сток «forest», а не «инструмент для измерения»).
- Если по запросу видео не нашлось — запрос автоматически упрощается (полный → первые 2 слова → общий). **Фото** используется только когда видео не нашлось вообще ни по одному варианту, и обрезается сервером Pexels ровно в 1920×1080.
- Не перемещайте `stock_media/` до окончания работы над проектом — в XML абсолютные пути.
